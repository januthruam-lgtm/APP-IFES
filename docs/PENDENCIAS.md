# Pendências e Próximos Passos Futuros • Brain Studio

Registros de melhorias opcionais de longo prazo e auditorias externas que dependem de certificações de terceiros:

1. **Auditoria Externa de Acessibilidade (WCAG)**:
   - Conduzir auditoria externa independente com utilizadores reais de leitores de tela (TalkBack / NVDA) antes de reintroduzir qualquer selo formal de conformidade WCAG AAA. No momento, o app usa com precisão o rótulo *"Acessibilidade e Inclusão"*.

2. **Novos Conectores Institucionais Universais**:
   - Expansão dos conectores multi-instituição (SIGAA, Blackboard, Canvas) conforme os conectores forem certificados.

3. **Notificações Push Nativas (Capacitor)**:
   - Configuração de credenciais APNs/FCM para push notifications remotas em builds de produção para Play Store.
